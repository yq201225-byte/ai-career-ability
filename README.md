# AI 职业能力转化平台

一个面向 AI 学习者和 AI 产品经理求职者的个人项目 Demo。项目目标是把零散提问、代码理解、项目复盘和作品集表达沉淀为可复习、可验证、可表达的职业能力资产。

## 项目定位

用户在学习 AI 和准备 AI PM 求职时，常见问题不是“没有信息”，而是：

- 问完 AI 之后难以沉淀。
- 看懂概念但不会转成实操。
- 项目经历难以真实、清晰、有证据地表达。
- 作品集草稿容易出现夸大、缺证据或事实不清。

本项目将学习、练习、项目表达和资产沉淀串成一个闭环。

## 仓库内容

- `index.html`：公开版单文件 Demo，可直接打开。
- `docs/product-brief.md`：产品简报。
- `docs/fact-gate.md`：事实门禁机制。
- `docs/eval-and-badcase.md`：评测样例与 Badcase 处理。

## 当前版本

V0.4 Demo 覆盖 P0 主路径：目标确认、AI 学习助手、代码训练、作品集事实确认、能力资产中心。

## 展示边界

本仓库为个人项目公开材料，不包含任何实习公司资料、真实用户隐私、内部系统或不可公开文档。
